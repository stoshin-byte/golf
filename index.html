⛳️ ゲームルール一覧

1. ラスベガス（本線ルール）
  • ペア決定: 前ホールの実打数（ハンディなし）が良い順（1〜4番手）に並び、【青】1&4番 vs 【オレンジ】2&3番 で自動編成。
  • スコア合成: 良い打数を10の位に配置（例: 4打と5打 ➔ 45点）。数字が小さいチームの勝利。
  • バーディ逆転: 相手にバーディが出ると、自チームは悪い方の打数が10の位に繰り上がり（逆転）（例: 4打と5打 ➔ 54点）。
  • 両チームバーディ: 両チームとも逆転処理が適用され、10の位同士で正しく計算。
  • 引き分け: 10点を次回へ持ち越し。次回ホールは前ホールのチーム構成を固定して引き継ぎ。
  • 打数上限: スコア計算時の打数は最大9打。全18ホールで終了。
2. ハンディキャップ（HDCP）
  • スタート時に設定（ハンディなし / PAR4のみ / PAR4,5のみ / 全ホール）。
  • チームスコア計算時のみ打数から減算。次ホールの打順決め（オナー順）には影響しません。
3. ✨ オリンピック（ゼロサム精算）
  • 💎 ダイヤ (+5): 他3人から各5P（実質 +15P）※グリーン外からカップイン
  • 🥇 金 (+4): 他3人から各4P（実質 +12P）※1パット最長距離
  • 🥈 銀 (+3): 他3人から各3P（実質 +9P）
  • 🥉 銅 (+2): 他3人から各2P（実質 +6P）
  • 鉄 鉄 (+1): 他3人から各1P（実質 +3P）※1パット最短距離
4. ⚠️ ペナルティ（各 -2P / ゼロサム精算）
  • 3パット / 砂遊び / 池ポチャ / ワンペナ: 該当者が他3人へ各2P支払い（実質 -6P / 他3人は各 +2P）。
5. 🚩 チップ（ドラコン・ニアピン）
  • PAR3(ニアピン) / PAR5(ドラコン): 勝者は他3人から各10P獲得（実質 +30P）。該当者なしは次回同PARへ全額持ち越し。
